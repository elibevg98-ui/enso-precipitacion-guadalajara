# Scripts

Los scripts originales no estaban disponibles en la conversación. Cuando se incorporen, se recomienda separar:

- `01_preparar_datos.*`: carga, limpieza y cálculo de anomalías;
- `02_correlacion_desfases.*`: correlaciones ONI–lluvia;
- `03_fases_enso.*`: comparación de anomalías por fase;
- `04_figuras.*`: generación de las figuras publicadas.

Cada script debe indicar sus entradas, salidas, dependencias y cómo ejecutarlo. Los scripts no deben incluir contraseñas, claves ni rutas personales.
