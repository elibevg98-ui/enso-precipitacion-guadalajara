# Datos

Los datos fuente no fueron incluidos en la conversación y no se publican en este primer respaldo.

Antes de añadir archivos a este directorio, documente para cada conjunto:

- fuente y enlace de descarga;
- cobertura temporal y espacial;
- unidades y definición de variables;
- licencia o condiciones de uso;
- transformaciones aplicadas;
- si contiene información restringida, personal o sensible.

Si un archivo es grande, sensible o tiene restricciones de redistribución, no debe subirse al repositorio público. En su lugar, incluya una descripción, un enlace oficial si existe y las instrucciones para obtenerlo.
